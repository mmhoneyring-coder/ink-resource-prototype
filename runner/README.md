# Balance Runner

ゲーム本体とは分離した、Ink Resource Prototype 用のバランス検証ランナー。

## 現在できること

- 現在の `app.js` と同じスプラッシュ生成パラメータで大量試行
- 180×280 / 220×360 / 240×420 / 260×450 の盤面比較
- 狙い方（全体、下→上、各層集中、ランダム）の比較
- 面積探索率の集計
- 円形資源を置いた資源命中率・平均命中個数の集計
- 資源サイズを各個体±25%でランダム化
- 盤面拡大時に資源サイズを緩く拡大する比較
- 資源数を「全盤面で同じ個数」または「面積比例」に切り替えて比較
- START位置、筆半径、仮の筆距離予算を変更可能
- スプラッシュ発見数、筆の途中での追加発見数、最終発見数、最終有効化数を集計

資源サイズの自動拡大は 180×280 を 1.00× とし、面積比の 0.32 乗で緩く増やす。現在のプリセットでは概ね 1.00 / 1.16 / 1.25 / 1.31 倍。

## 現在の第一候補

暫定値として以下をブラウザ版の初期値にしている。

- 盤面: 240×420
- 資源数: 40
- スプラッシュ: 8回
- 筆距離予算: 480
- 筆半径: 2
- START: 上から78%
- 最終有効化数の目安: 6〜10個程度

10個を必達・固定値にはせず、ランや戦略によって6〜10程度に散る状態を当面の評価目安にする。

## 仮の筆モデル

点数分布と総インク換算が未確定なので、現時点では距離だけを使う簡易モデル。

1. STARTを接続網の起点とする。
2. スプラッシュで見つかった未取得資源のうち、現在の接続網から最も近いものへ直線で筆を引く。
3. 筆の途中で完全隠し資源の当たり判定に触れた場合、その場で発見し、接続済みなので有効化扱いにする。
4. 筆距離予算が尽きるか、接続候補がなくなるまで繰り返す。

これはプレイヤーの最適行動を再現するものではなく、**筆を使うことで隠し資源がどの程度追加発見されるか**を見るための暫定ヒューリスティック。

## ブラウザ

GitHub Pages の `/runner/` から実行できる。

## CLI

例:

```bash
node runner/run.mjs --trials 500 --splashes 8 --strategy wide
node runner/run.mjs --trials 500 --resources 40 --resourceRadius 3 --resourceCountMode fixed --resourceScaleMode auto
node runner/run.mjs --trials 500 --resourceCountMode density --resourceScaleMode fixed --json
```

CLIはまだ探索・命中率まで。筆シミュレーションは現在ブラウザ版で確認する。

## まだ入れていないもの

- 層ごとの点数分布
- 見えている / 存在のみ見える / 完全隠しの正式な割合
- 特別なお宝
- スプラッシュと筆を共通単位にした総インク消費
- 点数を考慮した取得戦略

これらは仕様確定後に同じランナーへ追加する。
