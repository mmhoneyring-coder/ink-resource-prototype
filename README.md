# Ink Resource Prototype

インク系ゲームの別バージョンを、1人用スコアアタックとして検証するプロトタイプ。

## 現在の核

- 盤面は上層・中層・下層の3層。
- ターン制ではなく、合計100のインクを使い切るまで遊ぶ。
- スプラッシュは1回8インク。広く探索できるが、狙った位置からブレる。
- 筆は引いた長さに応じてインクを消費する。
- 資源は「得点まで公開」「位置だけ公開」「完全隠し」の3状態。
- 各層ごとに、得点まで公開1個・位置だけ公開1個。それ以外はインクが触れるまで見えない。
- インクが資源に触れると、完全隠し／位置のみの資源も得点まで判明する。
- 資源にインクが付いただけでは所有にならない。
- START／接続済みインクから筆でつなぎ、接続網が資源に触れた筆行動後に所有確定する。
- 資源は高得点ほど小さく、偶然ヒットしにくい。

## 現在の仮置き値

- 盤面: 260×450
- 通常資源: 40個
  - 上層14個
  - 中層13個
  - 下層13個
- 特別埋蔵: 50pt×1を通常40個とは別に追加
  - 下層または中層へ50%ずつ
  - 位置は完全非公開
- START: 上から78%
- 総インク: 100
- スプラッシュ: 8インク/回
- 筆: 1セルあたり0.075インク
  - 8回スプラッシュ後の残り36インク ≒ 筆距離480セル
- 筆1回の最大長: 56セル

### 通常資源の点数配分

- 下層: 2×2 / 3×2 / 4×2 / 5×2 / 6×2 / 8×3
- 中層: 6×2 / 8×2 / 10×2 / 12×3 / 14×2 / 16×2
- 上層: 14×2 / 16×2 / 20×3 / 24×3 / 28×2 / 30×2

### 得点と当たり判定サイズ

- 1〜3pt: 半径5.0
- 4〜6pt: 半径4.3
- 7〜10pt: 半径3.7
- 12〜16pt: 半径3.1
- 20pt以上: 半径2.6
- 50ptお宝: 半径1.8

これらはプレイ感確認用の仮値で、正式仕様ではない。

## 画面上の見え方

- 白系の資源: 得点まで公開
- 灰系で `?`: 位置のみ公開
- オレンジ系: インクが触れて取得資格があるが、まだ接続されていない
- 金色: 所有済み
- 「分布」ボタン: 各層の公開されている点数内訳を確認

## 操作

- スプラッシュ: 盤面をタップ
- 筆: STARTまたは接続済みインクからドラッグ
- 2本指: 縮小／拡大・表示移動
- `− / 65% / ＋`: 表示倍率の変更
- 同じ盤面でもう一度: 同じSeedで再挑戦

## バランス検証

`runner/` はゲーム本体と分離したバランス検証用。現在の点数・資源サイズ・公開状態・マップサイズなどは、プレイ結果を見ながらランナー側でも比較する。

## 既存 InkFront との関係

既存 `inkfront-preview` とは別実装。リアルタイム戦闘・濃度・霧・兵士等は持ち込んでいない。
