# Ink Resource Prototype

インク系ゲームの別バージョンを、1人用スコアアタックとして検証する最小プロトタイプ。

## 現在の核

- 盤面には最初から見える資源と、見えない資源がある。
- 1ターンに「スプラッシュ」または「筆」のどちらかを行う。
- スプラッシュは同じ1手消費で、複数の中小インク島をランダム生成する。
- 島は大きさ・個数・形・位置にばらつきがある。巨大な単発島は出さない。
- 隠し資源はインクが触れると公開される。
- 資源にインクが付いただけでは得点にならない。
- 本拠地／接続済みインクから筆でつなぎ、筆行動後に資源位置まで接続されていれば所有確定。
- 所有した資源は今回はポイントのみ。特殊効果は未実装。
- 24ターン終了時の得点を競う。

## 仮置き値

以下はゲーム性確認用で、正式仕様ではない。

- 24ターン
- 見える資源 7 / 隠し資源 15
- 1スプラッシュ: 中3〜5島、小1〜5島
- 筆1回の最大長: グリッド28
- 隠し資源には低確率で25点・50点の大物がある

`app.js` 冒頭の `CONFIG` に調整値を集約している。

## 既存 InkFront から参考にした点

既存 `inkfront-preview` の以下の設計を参考にしているが、ソースは別実装としている。

- セルベースのインク表現
- 接続済みインクの判定
- 本拠地／既存接続網から筆を開始する考え方
- Pointer Events によるマウス・タッチ共通入力

今回版では、リアルタイム戦闘・濃度・霧・兵士等は持ち込んでいない。

## GitHub Pages 公開

静的構成のため、Settings → Pages で `main` / `/(root)` を公開元に指定すればスマホからアクセスできる。
